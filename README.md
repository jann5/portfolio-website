# Jan Nawrot — Portfolio


[![GitHub](https://img.shields.io/badge/GitHub-100000?style=for-the-badge&logo=github&logoColor=white)](https://github.com/jann5)
[![Portfolio](https://img.shields.io/badge/Live_Portfolio-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://jann5.github.io/)

Wydajne portfolio osobiste pokazujące projekty webowe, interaktywne doświadczenia i podejście do rozwiązywania problemów w prosty, estetyczny sposób.


## 🚀 Przegląd

To portfolio to nowoczesna aplikacja webowa oparta na React, nastawiona na dopracowane doświadczenie użytkownika, płynne animacje i wyraźny, ciemny styl.

### Najważniejsze funkcje
- **Interaktywność**: efekt kursora, animacje i płynne przejścia.
- **Prezentacja projektów**: przewijana lista wybranych realizacji.
- **Storytelling**: warstwowe sekcje z efektami parallax.
- **Responsywność**: dopasowanie do telefonu, tabletu i desktopu.
- **Płynne przewijanie**: Lenis dla bardziej naturalnego ruchu strony.

---

## 🛠️ Stack technologiczny

| Layer | Technologies |
| :--- | :--- |
| **Frontend** | React 18, TypeScript, Vite |
| **Styling** | Tailwind CSS, shadcn/ui, Radix UI |
| **Animation** | Framer Motion, GSAP |
| **Scrolling** | Lenis Scroll, ScrollVelocity |
| **Validation** | Zod, React Hook Form |
| **Icons** | Lucide React |

## 📂 Struktura projektu

```text
src/
   ├── components/     # Reużywalne komponenty UI
   ├── pages/          # Sekcje układu strony
   ├── lib/            # Funkcje pomocnicze
   ├── hooks/          # Własne hooki React
   └── assets/         # Zasoby statyczne i style
```

## 🛠️ Uruchomienie

### Wymagania
- Node.js (v18 or higher)
- npm or bun

### Lokalny start

1. **Sklonuj repozytorium**
   ```bash
   git clone https://github.com/jann5/portfolio-website.git
   cd Portfolio-website
   ```

2. **Zainstaluj zależności**
   ```bash
   npm install
   # or
   bun install
   ```

3. **Uruchom serwer developerski**
   ```bash
   npm run dev
   ```

4. **Zbuduj wersję produkcyjną**
   ```bash
   npm run build
   ```
